How to customise for each blog post

1. Change the --bg-image on each .cover div to use a different photo
2. Edit the .cover__tag text (category)
3. Edit the .cover__headline — wrap any word in <span class="highlight"> to make it red
4. Edit the .cover__script line (the handwritten-style hook)
5. Edit the 3 .cover__check-item lines (key takeaways)

To save as an image: open this file in Chrome → right-click a cover → Inspect → find the .cover div → right-click in DevTools → "Capture node screenshot"
